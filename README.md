# Watch School

A vintage watch primer. Single-page site that teaches you how to read a watch - movements, complications, case and dial vocabulary.

## Stack

Single static `index.html`. No build step, no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploy

Hosted on Vercel as the `watch-school` project. `.vercel/` is gitignored - run `vercel link` to reconnect a fresh clone.
